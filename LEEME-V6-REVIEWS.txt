ARGENTINA BY AGUSTINA — V6 REVIEWS MODERADAS
================================================

ESTA VERSION AGREGA
- Botón "Leave a Review" en la web.
- Formulario modal: nombre, país, email opcional, estrellas y comentario.
- Protección básica anti-spam (honeypot).
- Endpoint seguro /api/reviews para guardar en Sanity.
- Todas las reseñas nuevas entran con status = pending.
- La web sigue mostrando solamente status = approved.
- El token privado NO queda expuesto en el navegador.

IMPORTANTE: CONFIGURAR EL TOKEN UNA SOLA VEZ
1) Entrar a manage.sanity.io > proyecto > API > Tokens.
2) Crear un token nuevo con nombre: Website Review Writer
3) Elegir permiso Editor (o un rol personalizado que permita crear reviews).
4) Copiar el token. Sanity lo muestra una sola vez.
5) En Vercel: proyecto > Settings > Environment Variables.
6) Crear variable:
   Nombre: SANITY_WRITE_TOKEN
   Valor: pegar el token
   Entornos: Production, Preview y Development
7) Hacer un nuevo Deploy en Vercel.

PRUEBA LOCAL COMPLETA
El servidor live-server muestra la interfaz, pero no ejecuta /api/reviews.
Para probar el envío local, desde la carpeta principal ejecutar:

  npx vercel dev --listen 3000

La web se abre en:
  http://localhost:3000

En la primera ejecución puede pedir iniciar sesión en Vercel y vincular el proyecto.
La variable SANITY_WRITE_TOKEN también debe existir localmente. La forma más simple
es permitir que Vercel descargue las variables del proyecto vinculado.

FLUJO FINAL
Turista envía reseña -> Sanity Pending reviews -> Agustina aprueba -> aparece en la web.
