ARGENTINA BY AGUSTINA — V5 WEB CONECTADA A SANITY
==================================================

QUÉ INCLUYE
- La web pública lee contenido publicado desde Sanity.
- Articles dinámicos.
- Places dinámicos.
- Events dinámicos (solo eventos que todavía no terminaron).
- Reviews dinámicas: únicamente status = Approved.
- Website Settings controla título principal, subtítulo, email, WhatsApp y descripción SEO.
- Si Sanity está vacío o no responde, la web conserva contenido de respaldo y no queda rota.
- Web3Forms y el botón de WhatsApp siguen funcionando.

PROYECTO SANITY CONFIGURADO
Project ID: brjqcwkq
Dataset: production

IMPORTANTE: CORS DE SANITY
Para abrir la web localmente y para producción, agregá estos orígenes en:
Sanity Manage -> API -> CORS Origins

1) http://localhost:5500
2) http://127.0.0.1:5500
3) https://argentinabyagustina.com
4) https://www.argentinabyagustina.com

No marques "Allow credentials". La web hace solamente lecturas públicas.

PRUEBA LOCAL
1. Abrí la carpeta principal en VS Code.
2. Usá Live Server sobre index.html.
3. Publicá un contenido válido en Sanity.
4. Actualizá la web.

ORDEN RECOMENDADO PARA CARGAR CONTENIDO
1. Cities
2. Categories
3. Articles / Places / Events
4. Reviews (cambiar status a Approved)
5. Website Settings

No hace falta ejecutar npm para la web pública. npm run dev se usa solamente dentro del Studio de Sanity.
