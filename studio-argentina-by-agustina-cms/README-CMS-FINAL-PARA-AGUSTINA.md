# CMS final para Agustina

Esta versión está pensada para una persona sin conocimientos técnicos.

## Mejoras incluidas

- Inicio personalizado con mensaje de Miguel.
- Contadores reales y actualización automática cada 30 segundos.
- Aviso destacado cuando existen reseñas pendientes.
- Accesos rápidos a cada sección.
- Guía integrada sobre creación, publicación y moderación.
- Explicación sencilla de Borrador y Publicado.
- Menú reorganizado y completamente en español.
- Enlaces directos a la página pública y a los datos de contacto.

## Publicar la actualización

Desde esta carpeta:

```powershell
npx sanity deploy
```

El contenido existente no se borra porque está almacenado en el dataset de Sanity.
