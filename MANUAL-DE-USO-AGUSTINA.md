# Argentina by Agustina 1.1 — Manual de uso

Este panel permite actualizar la web sin tocar código.

## Entrar al panel
1. Abrir Sanity Studio.
2. Iniciar sesión con la cuenta autorizada.
3. Elegir el módulo correspondiente.

## Publicar un artículo
1. Abrir **Articles**.
2. Presionar **+**.
3. Completar título, URL, resumen, ciudad, categoría, portada y contenido.
4. Presionar **Publish**.
5. El artículo aparecerá automáticamente en la web.

## Publicar un lugar
1. Abrir **Places** y crear uno nuevo.
2. Completar nombre, ciudad, categoría, dirección, mapa, descripción, portada y galería.
3. Mantener **Active** habilitado.
4. Presionar **Publish**.

## Publicar un evento
1. Abrir **Events**.
2. Completar título, inicio, fin, ciudad, lugar, descripción, portada y mapa.
3. Mantener **Active** habilitado.
4. Presionar **Publish**.

Los eventos vencidos dejan de mostrarse automáticamente cuando su fecha final ya pasó.

## Aprobar una reseña
1. Abrir **Reviews > Pending reviews**.
2. Leer la reseña.
3. Cambiar el estado a **Approved** para mostrarla o **Rejected** para rechazarla.
4. Presionar **Publish**.

Solo las reseñas aprobadas aparecen públicamente.

## Cambiar datos generales
En **Website settings** se pueden actualizar el título del sitio, textos principales, email, WhatsApp, Instagram y descripción SEO.

## Recomendaciones
- Usar imágenes horizontales y nítidas.
- Escribir resúmenes breves.
- No publicar datos privados de clientes.
- Revisar ortografía, fechas y enlaces antes de publicar.
