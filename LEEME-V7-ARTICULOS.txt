ARGENTINA BY AGUSTINA — V7 ARTÍCULOS COMPLETOS

QUÉ AGREGA
- Botón “Read Article” en cada artículo publicado.
- Página individual con título, portada, fecha, categorías y contenido completo.
- Soporte para encabezados, párrafos, listas, enlaces, citas e imágenes del editor de Sanity.
- Galería de fotografías.
- Botón para compartir el artículo.
- Botón “Plan My Trip” y regreso a todos los artículos.
- Metadata SEO dinámica básica por artículo.

PRUEBA LOCAL
1. Levantar Sanity: cd studio-argentina-by-agustina-cms ; npm run dev
2. Levantar la web desde la raíz: npx live-server --port=5500
3. En Sanity, abrir un artículo publicado y completar Article content.
4. Recargar la web y presionar Read Article.

IMPORTANTE
- Los artículos de prueba sin contenido pueden abrir con el cuerpo vacío.
- Para una prueba completa, cargá al menos un párrafo en Article content.
- No hace falta crear schemas nuevos ni ejecutar npm install.
